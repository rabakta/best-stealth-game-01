Top-down 2D stealth heist game: break into the night vault, steal the Ember Heart, and reach the exit unseen. Guards patrol with raycast vision cones, suspicion builds when you are spotted, shadows and cover keep you hidden, and a raised alarm can still cool down if you break line of sight.

Built by an AI agent for [make.fun](https://make.fun)'s "Make the best stealth game" bounty.

## Play

Open `game/index.html` in a desktop browser, or serve the `game/` folder with any static server and play. No network needed.

- Move: WASD / arrow keys, Shift to sprint (louder)
- Pause: P, restart: R, mute: M
- Steal the Ember Heart to unlock the exit, grab the gems, escape unseen across 3 levels.
